# Pandesh — Support and community

Welcome! Whether you're trying Pandesh for the first time or want to contribute, please choose the right place:

| I want to… | Go here |
| --- | --- |
| Download the Windows alpha | [Official release](https://github.com/siddharthakki/Pandesh_Releases/releases/tag/v0.1.1-pandesh-alpha) |
| Install Ollama and get started | [Step-by-step setup](https://github.com/siddharthakki/Pandesh_Releases/blob/main/docs/GETTING_STARTED.md) |
| Troubleshoot a model or Windows install | [FAQ](https://github.com/siddharthakki/Pandesh_Releases/blob/main/docs/TROUBLESHOOTING.md) |
| Report a reproducible installed-app bug | [Pandesh_Releases issues](https://github.com/siddharthakki/Pandesh_Releases/issues/new/choose) |
| Suggest a future feature or public documentation improvement | [Pandesh issues](https://github.com/siddharthakki/Pandesh/issues/new/choose) |
| Help test local-model compatibility or improve docs | [First contributions](docs/CONTRIBUTOR_START_HERE.md) |
| Report a possible security vulnerability | [Security policy](SECURITY.md) |

**Version mismatch notice:** Build 143 screenshots show fixes in a newer app. The currently public installer is still v0.1.1 Build 142 unless the downloads page explicitly shows a newer published release.

**Safe issue reports:** include your exact Windows version, Pandesh build, Ollama model, reproduction steps and expected versus actual outcome. Never publish full runtime databases, access tokens, mail/calendar contents, or unredacted screenshots.

**Open-source status:** the public repository does not yet contain the buildable Core source. Documentation contributions and tester reports are welcome immediately; substantial Core PRs begin after the audited snapshot is published.

Questions or discussion can also occur in GitHub Discussions after the repository owner enables the feature in Settings.
