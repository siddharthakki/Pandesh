Get started in three steps.

  1. Install Ollama. Get the local model runtime from ollama.com.
  2. Download a model. For example, run ollama pull qwen2.5-coder:3b in PowerShell.
  3. Install Pandesh. Download the official alpha, verify SHA-256 and start a chat.
Know before you install: Pandesh is experimental and unsigned. Not all agent tools are ready on every model or PC. External services require separate permissions. Local-first does not mean connected services are offline.
