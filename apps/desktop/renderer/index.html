                One-time setup: your Google OAuth client
                
              Google requires every app to sign in with an OAuth client. Yours stays on this PC — Panda never sends it anywhere except Google.
              
                
                
                  
              1. Create or pick a Google Cloud project. 
                2. 
                  
              2. Enable the Gmail API and the Google Calendar API for that project.  
                3. 
                  
              3. Set up the OAuth consent screen: choose External, then add your own Google account under Test users. While the app is in Testing, Google signs you out every 7 days — just reconnect. 
                4. 
                  
              4. Create credentials → OAuth client ID → application type Desktop app. No redirect address is needed; Panda uses a temporary local one (127.0.0.1) for Google's reply. 
                5. 
                  
              5. On the OAuth client page press Download JSON, then import that file below. Or copy the Client ID (and the Client secret if Google shows one) and paste them. Either way they go straight into encrypted storage on this PC — never type or paste them into the chat.
                6. 
                
              
                
              
                  
                  Recommended: you pick the file; Panda reads it locally.
